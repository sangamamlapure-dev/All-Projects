SOFTWARE REQUIREMENTS SPECIFICATION (IEEE 830)

For ProjectHub – Modern Capstone Management System
Author: Sangam Amlapure, Rohan Patil, Aniket Deshmukh, Priya Kulkarni
1. INTRODUCTION & SCOPE
This document specifies the software functional criteria for ProjectHub, designed for college project management using Flutter Web/Android and Supabase PostgreSQL.

2. ROLE-BASED ACCESS CONTROL (RBAC)
The system defines 4 immutable academic roles: Student, Faculty Mentor, HOD/Admin, and Panel Evaluation Member. Authentication is managed through Firebase Auth SDK with Supabase Row-Level Security (RLS) policies enforcing multi-tenant isolation.

Realtime Sync & FCM Pipelines
Firebase FCM Dispatcher: Triggers foreground & background isolates on task assignments and mentor feedback.
Supabase Realtime (WSS): Subscribes Flutter client state to PostgreSQL row-level CDC (Change Data Capture) events.
Row-Level Security (RLS): Ensures candidates only modify their assigned capstone sprint tickets while mentors hold verification permissions.
